# The tool sends email, and only on a click

The tool's promise was that it never submits. Some Job postings take
applications only by email, and there nothing can be filled for the user to
submit themselves. The promise is narrowed and kept: Fill still never submits a
form, and an Application email leaves only on the user's click on a message they
reviewed. No automatic, scheduled or send-on-approve path exists. The Apply
address is always one found on the page, picked from the page's own addresses
the way ADR 0008 lets a model pick a page Option, or typed by the user.
